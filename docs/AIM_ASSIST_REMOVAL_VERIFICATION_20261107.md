# 2026-11-07 操縦・射撃・表示の分離

通常の出撃の `main.ts → stepFixed → fireAircraft` を変更した候補です。両モードとも操縦量と旋回応答は敵配置に依存せず、Easyの敵追尾・画面外倍率・自機通常弾の補正を外しました。Easyは移動後の姿勢と実画面比で、円内・1.2km以内の生存中かつ保護中でない敵への発射可否だけを1回決めます。武器処理では対象を再選択せず、左右の機銃・機関砲の全4銃口から前方へ発射します。Normalは長押し射撃です。AI予測射撃、巡航、速度レバー、旗・得点・復活・保存先・公開設定は維持します。

操縦の指・キーが中央でも機首角を保ち、解放後に水平へ戻します。高さだけの画面変化は所有中の指と入力を引き継ぎ、次の座標で基点を合わせます。回転・幅変更・画面離脱・停止は入力を解除します。描画は固定tickの前後を同じ割合で補間し、自機・カメラ・敵味方・照準が同じ表示時点を使います。発射・命中・時計は確定tickの状態を使います。停止再開が次の描画前に完了しても、同期resetにより過去の姿勢を再利用しません。試合・round・機体世代の変更も補間しません。
