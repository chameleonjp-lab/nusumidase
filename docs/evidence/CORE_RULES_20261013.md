## 実装した挙動

携行機が撃破された場合、コアはその機体の撃破時の位置をコピーして保持します。安全地点への移動と30秒の自動帰還を削除し、復活した機体の移動も追従しません。従来の接近による自軍コアの即奪還と、相手側による再取得は保持しています。位置を特定できない非有限の不正データに対する既存の復旧だけは保持しています。

自軍コアの所在に関係なく、敵コアを先に1つ自基地へ持ち帰った側が勝利します。次ラウンドはありません。同じ固定stepに両陣営が帰還した場合は、移動線分が回収球へ入るfractionを再検証して早い側を勝者とし、完全同時だけ引分にします。既存の12分の時間制限は保持し、未回収なら引分です。

コア携行AIは、自軍コアが不在でも待機せず帰還します。基準の帰還経路のままでは20seedの無操作試合でAIの持帰りが0件となったため、敵基地から離れる経路の高度と横方向の間隔を広げました。機体・速度・火力・復活保護・コア位置を変更する代替処理は加えていません。変更後は元の20seedの検査が成功し、AIによる取得と持帰りを確認できました。これは各試合で必ずAIが勝利するという保証ではありません。
