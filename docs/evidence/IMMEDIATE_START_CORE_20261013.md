自軍の落下コアを担当するAIはその周囲を警戒し、触れて基地へ戻そうとする経路を使いません。説明・結果の内訳・通知を新ルールへ合わせました。旧版の記録形式と保存データは保持し、v1/v2/v3の最高記録を分離します。
