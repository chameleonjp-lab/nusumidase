# ヌスミダセ

公開ページ: https://chameleonjp-lab.github.io/nusumidase/

カイセンの機体・操縦・追従視点を継承した、一人用の空中旗取りゲームです。味方は自機と僚機4機、敵はAI5機。敵の機密コアを先に1つ自基地へ持ち帰った側が勝利します。

## どんなゲーム？

戦闘機で敵基地へ飛び込み、機密コアを奪って自分の基地へ運ぶ、1人用の「空中旗取り」ゲームです。敵機を何機倒したかではなく、コアを先に持ち帰れるかで勝敗が決まります。仲間や敵はAIが操縦します。

- **攻める**：敵基地のコアへ近づいて取得し、敵の追撃をかわして帰還します。
- **守る**：自軍のコアを運ぶ敵を迎撃します。運搬中の機体が撃墜されるとコアはその場所に落ちるので、再び拾われる前に周囲を守ることも大切です。
- **決着**：どちらかが1つ持ち帰れば終了。12分以内に決着しなければ引分です。撃墜後は復活できるため、失敗しても試合中に再挑戦できます。
- **操作**：画面のドラッグやPCの矢印キーで操縦。イージーは巡航・自動射撃の補助付き、ノーマルは射撃と速度を自分で操作します。

ホームでモードと操作方法を確認して出撃してください。出撃するとカウントダウンなしで試合が始まります。WebGL2に対応したブラウザが必要です。公開ページとリポジトリの版は同じとは限らないため、ゲーム内のルール説明も確認してください。

## 詳しいルール

出撃ボタンを押すとカウントダウンなしですぐに開始します。自軍コアの所在に関係なく、敵コアを持ち帰れば勝利します。自機・僚機・敵機のどれが運んでいても、撃墜されるとコアはその撃破地点に残ります。時間経過や所属チームの接触で基地へ戻ることはなく、相手チームがその場から拾い直して運べます。撃墜後は8秒で復活。12分の有効プレイ時間内にどちらも持ち帰れなければ引分です。完全に同時の持ち帰りも引分とし、陣営の処理順で勝敗を決めません。ルール版は `nusumidase-ctf-v3` です。

## 起動

公開用ファイルは `gh-pages` ブランチから配信します。`main` の変更は自動では公開されません。再公開の手順と公開したソースの確認方法は [公開手順](docs/PUBLISHING.md) を参照してください。

Node.js 24で検証しています。

```sh
npm ci
npm run dev
```

ブラウザーで表示されたローカルURL（既定は http://127.0.0.1:4177）を開きます。WebGL2が必要です。

```sh
npm test
npm run build
npx playwright install chromium webkit
npm run test:browser
```

Chromiumの実行ファイルは、`NUSUMIDASE_CHROMIUM_EXECUTABLE` があればその値、なければPlaywrightのインストール先を使います。WebKitも `NUSUMIDASE_WEBKIT_EXECUTABLE` で指定できます。この作業環境固有のWebKit依存設定は [検証記録](docs/evidence/VERIFICATION.md) に記載しています。

## 操作

- タッチ・マウス：ボタンのない場所から相対ドラッグで操縦。
- Normal：射撃、宙返り、縦速度レバー。レバーを離すと中央へ戻り、調整した目標速度は保持します。
- Easy：自動巡航・航空機への照準支援・自動射撃。タッチは宙返りだけ。
- PC既定：矢印で操縦、Spaceで射撃、Lで宙返り、W/Sで加減速、Escで停止・再開。Easyでは射撃・加減速を受け付けません。

操作設定でキーとタッチ操作の位置・大きさ・不透明度を変更できます。「保存」「今回だけ使う」「破棄」を選べます。説明や設定、非表示、描画喪失で停止した試合は、明示的に再開するまで進みません。

設定と完了した最新20試合・モード／ルール版別最高記録は端末内の `nusumidase-` 保存領域を使用します。安全な保存ロックが使えない環境では設定を「今回だけ使う」で適用でき、記録の保存失敗は画面に表示します。途中の試合は再読み込みで中断します。
