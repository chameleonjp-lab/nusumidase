# ヌスミダセ

カイセンの機体・操縦・追従視点を継承した、一人用の空中旗取りゲームです。味方は自機と僚機4機、敵はAI5機。敵の機密コアを自基地へ3回持ち帰ると勝利します。

自軍コアが奪われている間は回収できません。携行機が撃墜されるとコアは空中に落ち、30秒で自動帰還します。自軍機が接近すれば即奪還できます。撃墜後は8秒で復活。12分の有効プレイ時間が過ぎると回収数で判定し、同数は引分です。

## 起動

Node.js 24で検証しています。

```sh
npm ci
npm run dev
```

ブラウザーで表示されたローカルURL（既定は http://127.0.0.1:4177）を開きます。WebGL2が必要です。

```sh
npm test
npm run build
npx playwright install chromium webkit
npm run test:browser
```

Chromiumの実行ファイルは、`NUSUMIDASE_CHROMIUM_EXECUTABLE` があればその値、なければPlaywrightのインストール先を使います。WebKitも `NUSUMIDASE_WEBKIT_EXECUTABLE` で指定できます。この作業環境固有のWebKit依存設定は [検証記録](docs/evidence/VERIFICATION.md) に記載しています。

## 操作

- タッチ・マウス：ボタンのない場所から相対ドラッグで操縦。
- Normal：射撃、宙返り、縦速度レバー。レバーを離すと中央へ戻り、調整した目標速度は保持します。
- Easy：自動巡航・航空機への照準支援・自動射撃。タッチは宙返りだけ。
- PC既定：矢印で操縦、Spaceで射撃、Lで宙返り、W/Sで加減速、Escで停止・再開。Easyでは射撃・加減速を受け付けません。

操作設定でキーとタッチ操作の位置・大きさ・不透明度を変更できます。「保存」「今回だけ使う」「破棄」を選べます。説明や設定、非表示、描画喪失で停止した試合は、明示的に再開するまで進みません。

設定と完了した最新20試合・モード別最高記録は端末内の `nusumidase-` 保存領域を使用します。途中の試合は再読み込みで中断します。
